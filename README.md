# Portfólio — William Gabriel Meneghini

Portfólio pessoal responsivo voltado à apresentação de projetos, habilidades e objetivos profissionais nas áreas de **desenvolvimento front-end** e **suporte/TI**.

## Demonstração

[williamgabrielbm.github.io](https://williamgabrielbm.github.io)

## Destaques

- Identidade visual inspirada em terminal
- Layout responsivo para desktop e dispositivos móveis
- Animação de apresentação com JavaScript
- Seção de projetos com links para os repositórios
- Apresentação objetiva de foco e habilidades
- Navegação por âncoras com rolagem suave

## Tecnologias

- HTML5 semântico
- CSS3
- JavaScript
- Google Fonts
- GitHub Pages

## Executar localmente

1. Baixe ou clone o repositório.
2. Abra `index.html` diretamente no navegador ou use um servidor local.
3. Não há dependências, instalação ou etapa de compilação.

## Estrutura

- `index.html`: conteúdo e estrutura da página
- `style.css`: identidade visual e responsividade
- `script.js`: efeito de digitação da apresentação
- `logotransparente.png`: identidade visual
